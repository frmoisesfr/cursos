02

Matrices: organizar y transformar información

Álgebra matricial · NumPy

¿Qué es una matriz?

Una matriz es una tabla rectangular de números organizada en filas y columnas. Una matriz de m filas y n columnas tiene dimensión m × n.

A = [ [1, 2], [3, 4] ]

El elemento aij está en la fila i y columna j.

Operaciones importantes

  • Suma y resta: mismas dimensiones.
  • Producto por un escalar.
  • Producto matricial: columnas de A = filas de B.
  • Determinante: solo matrices cuadradas.
  • Inversa: existe si det(A) ≠ 0.

Python: crear y operar con matrices

NumPy · Operaciones matriciales
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("Matriz A:\n", A)
print("A + B =\n", A + B)
print("A - B =\n", A - B)
print("2A =\n", 2 * A)
print("A · B =\n", A @ B)  # Producto matricial
print("Transpuesta:\n", A.T)
print("Determinante:", np.linalg.det(A))
print("Inversa:\n", np.linalg.inv(A))
Ojo: en Python, A * B multiplica elemento a elemento. Para el producto matricial se utiliza A @ B.

Sistemas de ecuaciones lineales

De las ecuaciones a la solución · NumPy y SymPy

Forma matricial

Un sistema lineal puede escribirse como:

A · X = B

A contiene los coeficientes, X las incógnitas y B los términos independientes.

¿Cuántas soluciones tiene?

  • Compatible determinado: una solución.
  • Compatible indeterminado: infinitas soluciones.
  • Incompatible: ninguna solución.

El determinante permite estudiar sistemas cuadrados, pero no clasifica por sí solo todos los sistemas.

Python: resolver un sistema con NumPy

NumPy · Método numérico
import numpy as np

# Sistema:
# 2x + y = 5
# x - y = 1
A = np.array([[2, 1],
              [1, -1]], dtype=float)
b = np.array([5, 1], dtype=float)

solucion = np.linalg.solve(A, b)
print("Solución [x, y]:", solucion)

# Comprobación: A @ solucion debe ser igual a b
print("Comprobación:", A @ solucion)
print("Términos independientes:", b)
print("¿Coinciden?", np.allclose(A @ solucion, b))

Python: solución exacta con SymPy

SymPy · Álgebra simbólica
import sympy as sp

x, y = sp.symbols('x y')
ecuacion1 = sp.Eq(2*x + y, 5)
ecuacion2 = sp.Eq(x - y, 1)

solucion = sp.solve((ecuacion1, ecuacion2), (x, y))
print(solucion)

# Verificar sustituyendo la solución
print(ecuacion1.subs(solucion))
print(ecuacion2.subs(solucion))

Límites de funciones

Explorar el comportamiento de una función · SymPy y Matplotlib

Idea intuitiva

El límite describe el valor al que se aproxima f(x) cuando x se acerca a un punto, aunque la función no tenga por qué estar definida en él.

limx→a f(x) = L

Cómo investigarlo

  • Construir una tabla de valores cercanos a a.
  • Comparar aproximaciones por izquierda y derecha.
  • Visualizar la gráfica.
  • Calcular el límite simbólicamente.
  • Comprobar si existe continuidad.

Python: aproximación numérica y límite exacto

SymPy + NumPy + Matplotlib
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x = sp.symbols('x')
# Ejemplo: (x² - 1) / (x - 1)
f = (x**2 - 1) / (x - 1)

# Límite exacto
limite = sp.limit(f, x, 1)
print("Límite cuando x tiende a 1:", limite)

# Tabla de aproximación
for valor in [0.9, 0.99, 0.999, 1.001, 1.01, 1.1]:
    print(valor, float(f.subs(x, valor)))

# Gráfica evitando evaluar exactamente en x=1
funcion = sp.lambdify(x, f, 'numpy')
izq = np.linspace(0.5, 0.99, 200)
der = np.linspace(1.01, 1.5, 200)
plt.plot(izq, funcion(izq), label='f(x)')
plt.plot(der, funcion(der))
plt.axvline(1, linestyle='--', label='x = 1')
plt.axhline(2, linestyle=':', label='Límite = 2')
plt.scatter([1], [2], facecolors='none', edgecolors='red', s=90)
plt.title('Aproximación al límite')
plt.xlabel('x'); plt.ylabel('f(x)')
plt.grid(True); plt.legend(); plt.show()
Observa: la expresión original no está definida en x = 1, pero el límite existe y vale 2. La gráfica tiene un hueco en ese punto: límite y valor de la función no son lo mismo.

SymPy · Investigar límites laterales
import sympy as sp
x = sp.symbols('x')

f = sp.Abs(x) / x

lim_izquierda = sp.limit(f, x, 0, dir='-')
lim_derecha = sp.limit(f, x, 0, dir='+')
lim_total = sp.limit(f, x, 0)

print("Por la izquierda:", lim_izquierda)
print("Por la derecha:", lim_derecha)
print("Límite bilateral:", lim_total)
